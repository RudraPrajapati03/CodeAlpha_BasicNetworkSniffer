The NIDS demo uses Suricata to alert on ICMP Echo Requests. This is a test rule, not proof of malicious activity, and the demo does not automatically block traffic. See its [alert response playbook](./Task2/RESPONSE_PLAYBOOK.md) and [test report](./Task2/TEST_REPORT.md).

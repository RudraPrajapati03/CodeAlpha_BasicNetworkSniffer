# CodeAlpha Cyber Security Internship Projects

This repository contains three selected CodeAlpha cybersecurity internship projects.

## Task 1 — Basic Network Sniffer
Folder: [Task1/](./Task1/)

A Python/Scapy packet-sniffing learning tool with protocol summaries and PDF reporting. Use only on networks and devices you are authorized to monitor.

## Task 2 — Phishing Awareness Training
Folder: [Task2/](./Task2/)

A defensive training module with fictional examples, red flags, a safe-response guide, and a five-question quiz. It does not send phishing emails or collect credentials.

## Task 3 — Secure Coding Review
Folder: [Task3/](./Task3/)

An educational comparison of vulnerable and safer Python/SQLite patterns, password hashing, validation, unit tests, and a findings report.

## Safety
The vulnerable sample in Task 3 is for local education only and must not be deployed. Never collect real credentials for phishing-awareness demonstrations.

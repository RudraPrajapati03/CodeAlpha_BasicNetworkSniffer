# Task 2 — Phishing Awareness Training

**Internship:** CodeAlpha Cyber Security Internship — Task 2  
**Project type:** Defensive awareness and education

## Overview
A short training module that teaches learners to recognize phishing messages and fake websites, verify suspicious requests, and report messages safely. This project is designed for awareness training only. It does not send emails, collect credentials, or host fake login pages.

## Project files
- [PHISHING_AWARENESS_GUIDE.md](./PHISHING_AWARENESS_GUIDE.md) — objectives, lesson plan, fake-website checklist, response steps, and evaluation.
- [SAFE_EXAMPLES.md](./SAFE_EXAMPLES.md) — fictional examples with red flags and safe responses.
- [QUIZ.md](./QUIZ.md) — five-question knowledge check and answer key.

## How to use
1. Read the awareness guide.
2. Discuss each fictional example and identify the warning signs.
3. Complete the quiz without looking at the answer key.
4. Review incorrect answers and repeat the quiz if useful.
5. For a real suspicious message, follow your organization's reporting process.

## Deliverables and limitations
The learning materials and quiz are included in this repository. This is an educational awareness project, not a live phishing simulation, email scanner, or credential-collection tool. Do not run simulations against real people without explicit authorization and appropriate safeguards.

## Safety
All sample domains use the reserved `.example` suffix. Never enter real credentials or OTPs into a link from a suspicious message.

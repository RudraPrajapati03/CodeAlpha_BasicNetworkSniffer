# Task 4 — Network Intrusion Detection System (NIDS)

**Internship:** CodeAlpha Cyber Security Internship — Task 4  
**Engine:** Suricata 8.x  
**Platform tested:** Windows with Npcap

## Overview

This project demonstrates a rule-based NIDS using Suricata. It captures traffic on a selected network interface and writes alerts when traffic matches configured rules.

The included custom rule detects ICMP Echo Requests (commonly generated by `ping`). This is a controlled test rule: ping is normal traffic and is not inherently malicious. This demo validates packet capture, rule matching, alert logging, and CSV summarization; it is not a complete intrusion-detection ruleset.

## Custom test rule

```suricata
alert icmp any any -> any any (msg:"NIDS TEST - ICMP traffic detected"; itype:8; sid:1000001; rev:1;)
```

## Configure and validate

Run PowerShell from this Task4 folder. Update the Suricata executable/configuration paths if your installation differs.

```powershell
$base = (Get-Location).Path
$env:Path += ";C:\Windows\System32\Npcap"

& "C:\Program Files\Suricata\suricata.exe" -T `
  -c "C:\Program Files\Suricata\suricata.yaml" `
  -S "$base\rules\local.rules" `
  -l "$base\logs" `
  --set default-rule-path="C:\Program Files\Suricata\rules" `
  --set threshold-file="$base\threshold.config"
```

Expected validation message: `Configuration provided was successfully loaded. Exiting.`

## Start live detection

Use the correct Npcap interface identifier for your own machine. It may change between systems.

```powershell
$base = (Get-Location).Path
$env:Path += ";C:\Windows\System32\Npcap"

& "C:\Program Files\Suricata\suricata.exe" `
  -c "C:\Program Files\Suricata\suricata.yaml" `
  -S "$base\rules\local.rules" `
  -l "$base\logs" `
  --set default-rule-path="C:\Program Files\Suricata\rules" `
  --set threshold-file="$base\threshold.config" `
  -i "\Device\NPF_{REPLACE-WITH-YOUR-NPCAP-INTERFACE-ID}"
```

Keep the Suricata terminal open. In a second PowerShell window, test only your own network:

```powershell
ping -n 3 YOUR_GATEWAY_IP
Get-Content ".\logs\fast.log" -Tail 10
```

Replace `YOUR_GATEWAY_IP` with your current local gateway address. Expected: alerts containing `NIDS TEST - ICMP traffic detected`.

## Limitations and safety

- The current custom rule detects ICMP Echo Requests only; it does not detect every intrusion.
- This configuration generates alerts; it does not automatically block traffic.
- Treat alerts as signals for investigation, not proof of malicious activity.
- Test only on systems and networks you own or are authorized to monitor.
- Do not commit raw logs, packet captures, or CSVs containing sensitive environment details.
